Getting the most out of SSIM

Everything from your first account to running a few hundred. If something here is wrong or missing, say so on Discord and it gets fixed.

Getting started

SSIM is one file. There is no installer, no account to create and no licence key.

1. Download it

Get SSIM.exe from the Releases page. You need Windows 10 or 11, 64-bit, and about 500 MB of free space.

Only download from that page. SSIM handles your Steam passwords and 2FA secrets. A copy from a forum, a Discord message or any site offering an "unlocked" build is not worth the risk. If you want to confirm the file is genuine, see verify your download.

2. Give it its own folder

SSIM creates four folders next to itself the first time it runs: data, Vault, logs and mafiles. Put the exe somewhere sensible first, such as C:\SSIM\. Do not run it straight out of your Downloads folder.

3. Set a master password

On first launch SSIM asks you to choose one. It encrypts everything sensitive that SSIM stores on disk, and you will be asked for it each time the app starts.

There is no recovery. Nobody can reset this password for you, because nothing about it leaves your machine. If you lose it, your saved accounts are gone and you will have to add them again. Put it in a password manager now.

4. Open the dashboard

SSIM opens its own window with the dashboard inside. Everything runs on your computer; the dashboard is not reachable from the internet.

Adding your accounts

There are three ways in. Which one you pick decides whether SSIM can confirm trades for you.

MethodWhat you provideCan it confirm trades?
maFileA .maFile in Steam Desktop Authenticator formatYes
QR sign-inScan a code with the Steam mobile appNo, not until you add a maFile
Username and passwordCredentials plus your Steam Guard codeNo, not until you add a maFile

The difference matters. Confirming a trade or a market listing needs the account's 2FA secret, which only the maFile carries. QR and password sign-in give SSIM a session, so it can read inventories and place orders, but Steam will still ask you to approve each confirmation on your phone.

You can start with QR or a password and attach a maFile later. The account upgrades in place and keeps its history.

Passwords used for sign-in are not stored. SSIM exchanges them once for a session token and keeps the token, not the password.

Adding a lot of accounts at once

Drop all your .maFile files into the mafiles folder next to the app, then pick the ones you want from the import screen.

A maFile carries the 2FA secrets but not the account password. To import passwords at the same time, put a file called accounts.txt in that same mafiles folder, with one account per line:

mafiles/accounts.txtone per line
# lines starting with a hash are ignored
my_account_01:correcthorsebattery
my_account_02:hunter2:with:colons
  • The username is matched against your maFiles and is not case sensitive.
  • Only the first colon separates the two, so a password containing : works fine.
  • Blank lines and lines starting with # are skipped.
  • An account with no matching line is skipped from the import and tells you why.
  • Close the file in your editor before importing. If something else is holding it open, SSIM stops the import and names the file rather than importing half your fleet.

Two other routes exist for bulk work:

  • CSV import. One row per account, as username,password,shared_secret,identity_secret. Useful when you have the secrets but not the maFiles themselves.
  • Import another vault. If you already run SSIM elsewhere, merge that vault into this one.

These files are plaintext passwords sitting on your disk. Once the import has finished, delete accounts.txt and your CSV. SSIM does not delete them for you, and it does not need them again: the credentials are in the encrypted vault from that point on.

Organising a fleet

Once you have more than a handful of accounts, structure is what keeps it usable.

Environments

An environment is a group of accounts that share settings, most usefully a proxy. Every account belongs to one. You can read totals for a single environment, or across all of them at once.

Folders

Folders nest inside environments and are purely for your own organisation. Drag accounts between them, reorder them, and nest them as deep as you find useful.

Three levels of view

  • Account. One account's inventory, wallet and orders.
  • Environment master. Everything in one environment rolled into a single total.
  • Global master. Every account you have, in one figure.

Inventory and trade locks

SSIM loads inventories from your local cache instantly, then refreshes from Steam in the background.

A CS2 refresh pulls the full picture: your normal inventory, the contents of your storage units, and anything you currently have listed on the Market. TF2 inventories are supported as a read-only view.

Where your items sit

  • Owned. In the account's inventory and available.
  • Listed on Market. Currently on sale, so not tradable.
  • In a storage unit. Inside a casket. See storage units.

Trade locks

Every item shows whether it is locked and the exact date the lock lifts, read from Steam's own "Tradable After" note. Identical items stack together, but only when they share the same unlock date, so a stack is never hiding a locked item behind a tradable one.

You can also set a manual hold on an account, which makes SSIM treat its items as locked until a date you choose. Useful when you want to leave something alone without remembering why.

A refresh will never wipe a known-good inventory because Steam returned an empty or partial answer. If the read looks wrong, SSIM keeps what it already had.

Storage units

Caskets are read properly rather than shown as a single opaque item.

SSIM lists what is inside each storage unit and counts it towards the account's total, so nothing hides. You can move items in and out, and SSIM checks afterwards that the move actually happened rather than assuming it did.

Trading

Sending items

Send from one account to any trade URL, or select items across a whole folder and send them all to one destination in a single run. Balances and trade locks are checked before anything is sent, and each offer is confirmed by 2FA on your machine. A progress bar shows the run as it goes.

Offers, both directions

The offer manager pulls every incoming and outgoing offer from all your accounts into one list, with each side priced from your cache so you can see what an offer is actually worth. Accept, decline or cancel individually or in batches.

Auto-accept between your own accounts

Optionally, SSIM can automatically accept incoming offers that came from accounts you manage. Offers from anyone else always wait for you.

Trades are final. SSIM checks what it can before sending, but an accepted offer cannot be undone. Use the preview.

The Steam Market

Buying

Search for an item, pull its current lowest asking price with one click, set your price and quantity, and place the order. SSIM confirms it for you. The order then rests on the Market until it fills, exactly as it would if you had placed it yourself.

You can also run a buy across a folder, where each account buys as much of one item as its wallet allows. Balances are re-checked before the run starts.

Selling

List at the current lowest price, undercut it, or name the exact amount you want to end up with. SSIM shows you what will actually land in the wallet after Steam's cut, before anything goes live. Select items across accounts and list them in one run.

Selling a lot at once needs proxies. To price a sale, SSIM has to ask Steam what each item is currently going for. A big listing run means a lot of those lookups in a short window, and Steam will rate limit your IP address well before the run finishes.

Selling a handful of items is fine on a normal connection. If you are listing in bulk, set up proxies first, so the price lookups are spread across several addresses instead of hammering one.

Open orders

One screen shows every live sell listing and every resting buy order across the fleet. Cancel any of them from there, individually or in bulk.

Every price is shown in that account's own Steam wallet currency, formatted correctly. There is no hidden conversion.

Trade-up contracts

SSIM can look through what you already own and work out which ten-item contracts are worth running, then build them for you.

Trade-ups cannot be reversed. Ten items go in and one comes out. SSIM asks you to confirm before it runs one.

Prices and value

Where prices come from

By default SSIM prices items from the Steam Market. If you have a CSFloat API key you can switch to CSFloat instead, per your preference. Prices fill in the background so browsing stays fast, and SSIM falls back to Steam if a CSFloat key is missing.

Display currency

Item values can be shown in USD or EUR whichever you prefer, using a live exchange rate. This is only how totals are displayed to you. Buying and selling always happens in the account's real wallet currency.

Value history

Every time an account refreshes, SSIM records what its items are worth and what is in its wallet. That builds a curve of your real holdings over time, per environment and across everything.

Proxies

Optional for a few accounts. Effectively required once you are working in bulk.

Everything SSIM does goes through Steam's web endpoints, and Steam rate limits by IP address. A handful of accounts on one connection is fine. Refreshing a large fleet, or pricing a big list of items to sell, is not: you will be throttled partway through. Spreading that work across proxies is what keeps a bulk run from stalling.

Assign an HTTP or SOCKS proxy to a single account, or to a whole environment so every account in it uses the same one. A per-account proxy always wins over the environment's. With neither set, the account uses your normal connection.

A built-in checker shows each proxy's exit IP, country and response time, so you can see which ones are actually working before you rely on them.

Changing an account's proxy signs it out and back in, so the new connection is used from the next request onwards rather than halfway through a session.

Updates

SSIM checks GitHub for a newer release when it starts, and can install it before the app opens. The download is checked against a signature before anything is replaced, and a file that does not match is rejected rather than installed.

Verify your download

Optional. Skip this if you downloaded from the Releases page and are not worried.

Every release publishes a SHA256SUMS file alongside the exe. To check your copy matches, open PowerShell in the folder containing SSIM.exe:

Check the file's fingerprintPowerShell
Get-FileHash .\SSIM.exe -Algorithm SHA256

Compare what it prints with the line in SHA256SUMS from the same release. If they differ, do not run the file, and please report it.

Releases are built automatically from the public source by GitHub, which also records where each file came from. If you have the GitHub CLI, you can confirm that too:

Confirm it was built from this repositoryGitHub CLI
gh attestation verify SSIM.exe -R Santerxyz/SSIM

Coming from a closed-beta build

SSIM was never sold. During the closed beta it was gated by a licence server, which is how access was limited to invited testers. The beta is over, and from v1.5.0 that gate is gone. There is nothing to migrate.

  • The licence check is gone. SSIM no longer contacts any server of ours, and no longer fingerprints your machine or holds a seat.
  • Any licence files you still have are simply ignored. You do not need to remove them.
  • Updates now come from GitHub instead of the old server.
  • Your accounts, vault and history carry over. Point the new exe at the same folder.

Troubleshooting

I forgot my master password

There is no way back. The password is what encrypts your saved accounts, and it is never sent anywhere, so there is no reset. Delete the Vault folder to start fresh and add your accounts again.

SSIM will not start, or nothing happens

Only one copy can run at a time. Check whether it is already running before starting another. If it still will not open, the logs folder next to the exe records what happened, and that file is the useful thing to attach when asking for help.

An account will not sign in

Usually the saved session has expired and needs the account signing in again. If the account uses a proxy, check the proxy is alive with the built-in checker first, since a dead proxy looks a lot like a login failure.

Steam is rejecting requests or rate limiting me

Slow down and spread the work out. Refreshing every account at once, repeatedly, is the usual cause. Per-account proxies help considerably at scale.

My inventory looks wrong or incomplete

Refresh the account again. SSIM deliberately keeps the last good inventory rather than replacing it with a partial answer from Steam, so a stale view usually means the last read did not complete.

Something else

Ask on Discord, or open an issue on GitHub where it stays findable for the next person.
